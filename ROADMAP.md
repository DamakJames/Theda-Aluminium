# THEDA Aluminium Ltd - Strategic Digital Roadmap

This document outlines the planned future enhancements for the THEDA Aluminium Ltd corporate website, moving from a static brochure site to a fully dynamic digital platform.

## Phase 1: Core Corporate Site (Completed)
- [x] Complete visual rebranding from Pathfinder to THEDA Aluminium Ltd.
- [x] Responsive layout with custom CSS variables and utility classes.
- [x] Development of core pages: Home, About, Services, Projects, and Contact.
- [x] Static content integration detailing history, core services, and contact info.
- [x] Initial deployment configuration for Vercel.

## Phase 2: Dynamic Content & CMS Integration (Planned)
- **Database Setup:** Connect to a headless CMS (like Sanity) or a database (like Supabase) to manage dynamic content.
- **Dynamic Projects Portfolio:** Allow the administration team to easily upload new project photos, descriptions, and categories without editing code.
- **Dynamic Testimonials:** Implement a database table to store and randomly display authentic client testimonials on the homepage.
- **Contact Form Backend:** Integrate the `/contact` form with an email service (e.g., EmailJS, SendGrid) to route inquiries directly to `thedaaluminiumltd@gmail.com`.

## Phase 3: Content Marketing & SEO (Planned)
- **Blog Integration:** Create a `/blog` section where THEDA can post articles about roofing tips, industry news, and material guides to boost organic search traffic.
- **Advanced SEO:** Implement dynamic meta tags, Open Graph images, and structured JSON-LD data across all pages to improve Google search visibility.
- **Analytics:** Integrate Google Analytics and Google Search Console to track visitor behavior and lead conversion rates.

## Phase 4: Client & Partner Portal (Future)
- **Quotation Generator:** Build an interactive calculator where clients can input their roof dimensions and desired materials to get a rough estimate before contacting sales.
- **Partner Login:** Create a secure portal for contractors and architects to download technical specifications and CAD drawings of THEDA structural roofing systems.
- **Online Store (Optional):** Re-introduce e-commerce capabilities specifically for ordering standard roofing sheets, accessories, and maintenance supplies online.
